关掉浏览器标签后，GitHub Codespaces 仍可能在远程继续跑；计算停掉后，磁盘占用也还会继续计入存储用量。适用场景是：用量里计算已停但存储还在累积、准备删环境又怕丢掉改动，或误以为关标签就等于停止计费。处理方向是：把关标签、停止计算、保留存储、删除环境分成四件不同的事；先把未保存、未提交、未推送以及未跟踪文件落到远程仓库或导出分支，再决定只停止还是删除。删除不能把本计费周期里已经产生的用量追溯清零，也不等于此后零费用。依据 [Understanding the codespace lifecycle](https://docs.github.com/en/codespaces/about-codespaces/understanding-the-codespace-lifecycle) 与 [Stopping and starting a codespace](https://docs.github.com/en/codespaces/developing-in-a-codespace/stopping-and-starting-a-codespace)。

## 关标签、停止计算和删除不是一回事

生命周期从创建开始，到删除才结束。断开再连上，不会停掉正在跑的进程。在 VS Code 网页客户端里关掉浏览器标签，远程机器上的环境仍在运行。没有明确停止时，会一直跑到无操作超时（默认 30 分钟，可改）；超时后数据保留到上次保存。即使一直在用，单个环境最长也只有 12 小时，接近上限会提示先停止再重连：数据会先保存，再自动停止，要继续工作就重启。

只有正在运行的环境会产生 CPU 费用；停止后仍会产生存储费用。创建之后，无论在跑还是已停止，存储都会一直累计，直到删除。所以「已经 Stop」只说明计算停了，解释不了存储为什么还在。

需要停计算时，打开 [Your Codespaces](https://github.com/codespaces)，在目标名称右侧点省略号（...），再点 Stop codespace。也可用 GitHub CLI 的 gh codespace stop，或在 VS Code 命令面板（Mac 为 Shift+Command+P，Windows/Linux 为 Ctrl+Shift+P）输入 stop，选择 Codespaces: Stop Codespace。停止后，运行中的进程结束，已保存改动下次启动仍在；终端历史会保留，窗口里当时看见的内容不会保留。重启可点名称，选择浏览器或 VS Code；命令面板输入 connect，选择 Codespaces: Connect to Codespace。改机器类型等配置，通常要停止再启动才生效。

## 清理前先保住未提交和未跟踪文件

环境一旦删除，里面的工作一并消失。要持久保存，必须把改动提交并推送到远程仓库；从模板创建的，还需要发布到新的远程仓库。网页编辑器会自动保存（延迟写入）；桌面版 VS Code 需要自行打开自动保存。退出时若有未保存内容，编辑器会提示保存，但保存到云虚拟机并不等于已经在 GitHub 仓库里。

停止或删除前至少核对四类内容：编辑器里尚未保存的文件；已修改未提交；已提交但未推送（删除时编辑器会提醒存在未推送到远程分支的提交，可先推再删，或继续删除并放弃未提交改动）；git 未跟踪文件——它们不会进入提交，推送也带不走，删除后同样没了。连接不稳时应更频繁提交并推送。断网时进不去环境，未提交改动会按上次保存保留，恢复网络后可回到原状。

不想为了带走改动再开一个新环境时，可以把代码导出到新分支。每次新建环境开发时，应定期推送，让提交落在 GitHub 上；长期使用同一环境时，开始工作应从仓库默认分支拉取。重建容器时，`/workspaces` 以外的改动会被清掉，目录内（含克隆的仓库或模板）会保留。不要把重建或停止当成备份。

## 停止、自动删除与手动删除怎么选

还要回来改、只想先停计算：停止即可，存储仍会累计。出错或异常时，可以先停，再选择重启或删除。

长期不用：已停止且一段时间不活动会被自动删除，默认 30 天，可改保留期。自动删除同样会清掉未推送工作，不能代替事先推送。

远程已有需要的提交、未跟踪文件已纳入版本或已复制走之后，再手动删除。删除不能减少本月计费周期里已经累计的应计用量。不要指望「删掉就能把本周期账单打回零」，也不要把停止理解成零费用。

创建数量和同时运行数量都有上限，具体因账号等因素而异。到上限再创建会被要求先删一个；到同时运行上限再启动会被要求先停一个。

常见失败：关标签以为已经停计费（计算可能还在跑）；停了以为存储也停（存储计到删除为止）；删之前没检查未跟踪文件；把超时或 12 小时自动停止当成已经删除。替代办法是：用量仍高且列表里还有该环境，先到管理页确认是 Running 还是 Stopped；代码还没上远程就不要删；只需省计算时停止，确定不要环境再删。单价与套餐以账户账单说明为准，此处不罗列未核实价格，也不承诺清理后零费用。
